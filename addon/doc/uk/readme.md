# Vis Aware

Vis Aware — це додаток для NVDA, призначений для розпізнавання тексту (OCR), опису зображень, автоматичного розпізнавання та керування комп’ютером за допомогою ШІ.

Більшість сервісів потребують підключення до Інтернету та облікових даних для доступу до них. Vis Aware також містить RapidOCR для роботи в повністю автономному режимі. Ви можете використовувати Ollama для самостійного розміщення локальних моделей, таких як моделі Gemma з відкритим кодом від Google.

## Швидкий старт

1. Відкрийте `Меню NVDA > Параметри > Налаштування Vis Aware...`. У панелі **Загальні** введіть дані свого [облікового запису NVDACN](https://nvdacn.com/admin/login.php), щоб користуватися відповідними безкоштовними сервісами спільноти, які наразі включають опис зображень Vivo, OCR та сервіси мовних моделей загального призначення.

    - Якщо у вас є доступ до API від іншого постачальника моделей, наприклад Kimi, DeepSeek або Gemini, налаштуйте його у відповідній панелі **OCR**, **Опис зображень** або **ШІ помічник**.

    - Натисніть **Гаразд**, щоб зберегти налаштування.

2. Натисніть `NVDA+Alt+1`, щоб вибрати режим: **OCR**, **Опис зображень** або **ШІ помічник**.

3. Натисніть `NVDA+Alt+2`, щоб вибрати сервіс для поточного режиму. Оберіть сервіс, налаштований на кроці 1. Якщо ви увійшли в NVDACN, можете вибрати сервіс Vivo.

4. Натисніть `NVDA+Alt+3`, щоб вибрати джерело розпізнавання: **Об’єкт навігатора** або **Зображення чи файл зображення у буфері обміну**.

5. Натисніть `NVDA+Alt+Пробіл`, щоб розпочати розпізнавання у вибраному режимі:

    - Одне натискання показує результат у документі результатів розпізнавання NVDA. Для результатів OCR натисніть `Enter` або `Пробіл` на тексті, щоб виконати клацання мишею у відповідному місці. Це корисно для вікон із нестандартним способом показу інтерфейсу, які недоступні для екранних зчитувачів.

    - Поведінка при подвійному натисканні залежить від того, чи вибрано функцію **«Показувати текстові результати у повідомленні тільки для читання»** у розділі **«Загальні»**. Якщо ця функція вибрана, результат показується у діалозі режиму огляду NVDA, що корисно для математичних формул, таблиць та іншого вмісту, який потребує показу за допомогою Markdown. В іншому випадку NVDA озвучує результат без відкриття діалогу.

    - У режимі **ШІ помічник** введіть завдання, яке має виконати штучний інтелект. Це корисно для вікон із нестандартним способом показу інтерфейсу, які недоступні для екранних зчитувачів, а також для складних багатоетапних завдань.

6. Під час виконання завдання натисніть `NVDA+Alt+Пробіл` у будь-який момент, щоб зупинити його або розпочати нове завдання розпізнавання.

## Режими та джерела розпізнавання

Vis Aware пропонує три режими:

* **OCR** розпізнає текст на зображенні.
* **Опис зображень** описує візуальний вміст. Сервіси, які підтримують додаткові запитання, можуть давати відповіді на запитання щодо попереднього опису зображення.
* **ШІ помічник** аналізує екран і виконує дії на комп’ютері для виконання завдання.

OCR та опис зображень можуть використовувати такі джерела розпізнавання:

* Об’єкт навігатора
* Весь екран
* Поточне активне вікно
* Зображення або файл зображення в буфері обміну

У режимі «ШІ помічник» знімок усього екрана створюється безпосередньо, а вибране джерело розпізнавання не використовується.

## Налаштування

Усі налаштування Vis Aware доступні в меню `NVDA > Параметри > Налаштування Vis Aware...`.

Діалог налаштувань містить такі панелі:

* **Загальні**: показ результатів, копіювання результатів у буфер обміну, автоматичне читання, ведення журналу налагодження, джерела, які входять до циклу перемикання джерел, режим Vis Aware та дані облікового запису NVDACN.
* **Автоматичне розпізнавання**: тип розпізнавання, сервіс, підказка, модель, отримання назв моделей та налаштування використання знімків екрана для вебзображень.
* **OCR**, **Опис зображень** та **ШІ помічник**: поточний сервіс, увімкнення або вимкнення сервісів та налаштування, що надаються кожним сервісом.

Ви можете вимкнути сервіси, якими не користуєтеся. Вимкнені сервіси пропускаються під час звичайного використання та циклічного перемикання. Щонайменше один сервіс має залишатися увімкненим у кожному режимі.

## Команди та жести

Наступні команди мають початкові комбінації клавіш:

| Команда | Комбінація |
| --- | --- |
| Перемикання режиму Vis Aware | `NVDA+Alt+1` |
| Перемикання сервісу для поточного режиму | `NVDA+Alt+2` |
| Перемикання джерел розпізнавання | `NVDA+Alt+3` |
| Запустити розпізнавання з поточними налаштуваннями | `NVDA+Alt+Пробіл` |
| Задати додаткове питання щодо опису попереднього зображення | `NVDA+Alt+Q` |

Наступні команди початково не мають призначених комбінацій клавіш. Призначити їх можна в діалозі NVDA **«Жести вводу»**:

* Описати вміст поточного об’єкта навігатора.
* Описати зображення з буфера обміну.
* Задати питання перед описом зображення.
* Розпізнати вміст поточного об’єкта навігатора за допомогою OCR.
* Розпізнати текст на зображенні з буфера обміну за допомогою OCR.
* Показати попередній результат розпізнавання.
* Скасувати поточне розпізнавання.
* Перемикання режимів автоматичного розпізнавання: вимкнено, опис зображень та OCR.

## Результати розпізнавання

Залежно від налаштувань результати розпізнавання можуть показуватися у документі результатів розпізнавання NVDA, озвучуватися безпосередньо або показуватися у режимі огляду. У режимі огляду відображається підтримувана розмітка Markdown та математичні формули. Результати також можна скопіювати в буфер обміну.

Якщо результати OCR містять координати, натисніть `Enter` або `Пробіл` на тексті в документі результатів розпізнавання, щоб імітувати клацання мишею у відповідному місці екрана.

Зберігається лише останній результат розпізнавання поточного сеансу NVDA.

Команда додаткового питання відкриває діалог у форматі чату для сервісів опису зображень, які підтримують додаткові питання.

У цьому діалозі комбінація `Control+Enter` надсилає питання, а `Escape` — скасовує запит або закриває діалог.

Скористайтеся функцією **«Відкрити відформатовану відповідь»**, щоб переглянути розмову у режимі огляду, що корисно для математичних формул і вмісту з розміткою Markdown.

## Режим ШІ помічника

ШІ помічник спочатку запитує, яке завдання ви хочете виконати, починає з поточного активного вікна і може працювати у різних вікнах. Він може клацати мишею, вводити текст, натискати клавіші, прокручувати, перетягувати й відпускати об’єкти, здійснювати навігацію, очікувати та запитувати у вас інформацію за потреби. Дії не підтверджуються окремо, тому стежте за сеансом і зупиняйте його за потреби.

На кожному етапі роботи ШІ помічник надсилає знімок усього екрана до вибраного сервісу. Знімок може містити вміст інших вікон. Уникайте використання ШІ помічника, коли на екрані є конфіденційна інформація.

## Автоматичне розпізнавання

Автоматичне розпізнавання працює у фоновому режимі, коли фокус системи, курсор режиму огляду або об’єкт навігатора переміщується на підтримуваний графічний елемент керування. Результат озвучується автоматично та зберігається як останній результат розпізнавання. Додаткові питання доступні, якщо це підтримується сервісом.

Автоматичне розпізнавання початково вимкнено. На панелі **«Автоматичне розпізнавання»** виберіть OCR або опис зображень, а потім поточний сервіс або конкретний увімкнений сервіс.

Власна підказка та модель замінюють відповідні налаштування вибраного сервісу лише для автоматичного розпізнавання. Якщо поле підказки залишити порожнім, Vis Aware використає початкову стислу підказку (20–30 символів без Markdown).

Виберіть **«Використовувати модель, вибрану в налаштуваннях сервісу»**, щоб використовувати звичайну модель цього сервісу. Якщо це підтримується сервісом, скористайтеся функцією **«Отримати моделі»**, щоб завантажити список доступних назв моделей.

До списку сервісів автоматичного розпізнавання входять лише ті сервіси, які підтримують цю функцію. Якщо вибрано **«Поточний сервіс»**, а поточний сервіс не підтримує автоматичне розпізнавання, воно призупиняється та відновлюється після вибору сервісу, який його підтримує.

Для вебзображень Vis Aware зазвичай використовує URL зображення, а якщо він недоступний, використовує знімок екрана об’єкта. Якщо ввімкнено параметр **«Для об'єктів веб зображень Надавати перевагу знімкам екрана»**, Vis Aware спочатку розпізнає вміст, який показується на екрані, а якщо знімок екрана неможливо зробити, використовує URL зображення.

## Доступні сервіси

### Be My AI

Be My AI може описувати зображення та відповідати на додаткові запитання щодо того самого зображення. Щоб скористатися цим сервісом, відкрийте налаштування опису зображень, виберіть **«Увійти в Be My Eyes...»** і введіть адресу електронної пошти та пароль свого облікового запису Be My Eyes. Vis Aware не зберігає ваш пароль.

Цей сервіс підтримує ручний опис зображень та додаткові питання. Він не підтримує автоматичне розпізнавання, власні підказки або потокове отримання відповідей. Якщо ви скасували додаткове питання після його надсилання, розпізнайте зображення ще раз, перш ніж ставити наступне питання. Інакше відповідь, отримана із затримкою, може бути пов’язана з наступним питанням.

Зображення та питання надсилаються до Be My Eyes. Доступність сервісу, обмеження облікового запису та доступні функції визначаються Be My Eyes і можуть змінюватися. Vis Aware не несе відповідальності за обмеження облікового запису, зміни сервісу, втрату даних або інші наслідки використання сервісу.

Дотримуйтеся чинних умов використання Be My Eyes та не надсилайте конфіденційну інформацію, якщо ви не готові прийняти пов’язані з цим ризики.

### Baimiao OCR / розпізнавання формул

Щоб скористатися [Baimiao OCR](https://baimiaoapp.com) або сервісом розпізнавання формул Baimiao, відкрийте налаштування сервісу OCR, виберіть **«Увійти в Baimiao...»** і введіть адресу електронної пошти або номер мобільного телефону та пароль свого облікового запису Baimiao. Обидва сервіси використовують один сеанс входу.

Vis Aware зберігає постійний ідентифікатор цього пристрою, а також ім’я або частково прихований ідентифікатор для входу та рівень членства, зазначені на кнопці в налаштуваннях. Ці дані захищено за допомогою Windows DPAPI; пароль не зберігається.

Сервіс розпізнавання формул повертає як текст, так і формули. У результатах, показаних у режимі огляду, формули доступні для читання за допомогою екранного зчитувача.

Обидва сервіси використовують [вебверсію Baimiao](https://web.baimiaoapp.com/). Обмеження кількості пристроїв, квоти та доступні функції визначаються Baimiao і можуть залежати від облікового запису.

Вихід з облікового запису у Vis Aware видаляє збережені на цьому комп’ютері дані сеансу входу, але не гарантує виходу цього пристрою з облікового запису Baimiao. Вийдіть з облікового запису на пристроях, якими більше не користуєтеся, за допомогою мобільного застосунку Baimiao.

Ця інтеграція використовує непублічний вебінтерфейс Baimiao. Інтерфейс може змінитися або стати недоступним без попередження. Використовуйте його на власний ризик; Vis Aware не несе відповідальності за обмеження облікового запису, зміни сервісу, втрату даних або інші наслідки використання цього інтерфейсу. Дотримуйтеся чинних умов використання Baimiao.

### Apple Vision Server

Apple Vision Server — це сервіс OCR, який працює в локальній мережі. Vis Aware надсилає вибране зображення до застосунку для iOS з відкритим кодом [OCR Server](https://github.com/riddleling/iOS-OCR-Server), який використовує Apple Vision для розпізнавання тексту та повертає координати тексту. Обліковий запис хмарного сервісу OCR не потрібен, але комп’ютер та iPhone повинні мати можливість обмінюватися даними в одній локальній мережі.

Поточна версія застосунку потребує iOS 18.4 або новішої версії. Найстаріші підтримувані моделі — iPhone XS, iPhone XS Max, iPhone XR та iPhone SE (2-го покоління).

Щоб налаштувати сервіс:

1. Встановіть [OCR Server з App Store](https://apps.apple.com/us/app/ocr-server/id6749533041) на iPhone.

2. Підключіть iPhone та комп’ютер до однієї локальної мережі, а потім відкрийте OCR Server. Сервер запускається автоматично та показує адресу, яку потрібно використовувати.

3. Відкрийте `Меню NVDA > Параметри > Налаштування Vis Aware... > OCR`, увімкніть і виберіть **Apple Vision Server**, а потім введіть адресу, показану в застосунку, наприклад `192.168.1.10:8000`.

Для підключення до OCR Server використовується HTTP без автентифікації та шифрування. Використовуйте цей сервіс лише в надійній локальній мережі. У загальнодоступній або ненадійній мережі надіслані зображення та отримані результати OCR можуть бути перехоплені або змінені.

Під час використання цього сервісу залишайте OCR Server відкритим на передньому плані та не допускайте вимкнення екрана iPhone. Для безперервної роботи дотримуйтеся інструкцій розробників OCR Server щодо увімкнення функції «Керований доступ» в iOS. У документації цього проєкту також описано використання застосунку та API сервера.

### Рекомендоване офлайн-налаштування: локальні моделі через Ollama

Для автономної конфігурації з власним сервером ми рекомендуємо використовувати [Ollama](https://ollama.org/), щоб запустити локально модель з підтримкою обробки зображень. Після завантаження моделі та налаштування URL-адреси API, що вказує на локальний сервіс, Vis Aware надсилає зображення до цього сервісу.

Можна ввести повний URL API або назву хоста та порт, наприклад `localhost:11434`. Початковий базовий URL API — `http://localhost:11434/api`.

Скористайтеся функцією **«Отримати моделі»**, щоб завантажити назви моделей, а потім виберіть модель. Якщо модель не вибрано, використовується перша модель, повернута Ollama.

Ключ API необов’язковий. Сервіси Ollama потребують моделі з підтримкою обробки зображень, наприклад Gemma 4. Ollama OCR надає координати екрана лише тоді, коли модель повертає дійсні структуровані дані OCR.

### Інші сервіси

* PaddleOCR підтримує API завдань, розміщений на AI Studio, розгорнутий сервіс AI Studio або локально розміщений сервіс PaddleOCR. У налаштуваннях сервісу виберіть PaddleOCR або PaddleOCR-VL як тип сервісу.
* Сервіси Kimi використовують протокол, сумісний з OpenAI. Для платформи Kimi Open Platform введіть ключ, створений на [Kimi Open Platform](https://platform.kimi.com/console/api-keys). Для міжнародної платформи введіть ключ, створений на [міжнародній платформі Kimi](https://platform.kimi.ai/console/api-keys). Не використовуйте кінцеву точку одного сервісу з ключем іншого. Початкова модель — Kimi K3; доступні моделі та параметри міркування залежать від кінцевої точки й сімейства моделей.
* Сервіси DeepSeek використовують протокол, сумісний з OpenAI. Установіть базову URL-адресу `https://api.deepseek.com`, створіть ключ у [консолі API DeepSeek](https://platform.deepseek.com/api_keys) та введіть його в налаштуваннях сервісу. Початкова модель для роботи із зображеннями — `deepseek-flash`; її використовують сервіси опису зображень і ШІ помічника.

## Дані та облікові дані

Функція розпізнавання надсилає вибране зображення та, за необхідності, підказку до вибраного сервісу розпізнавання відповідно до його налаштувань.

На кожному етапі роботи ШІ помічник надсилає знімок усього екрана до вибраного сервісу; знімок екрана може містити інші вікна.

Ознайомтеся з політикою щодо даних сервісу та уникайте надсилання конфіденційного вмісту.

У підтримуваних системах з NVDA 2026.3 або новішою версією ручне й автоматичне розпізнавання екрана може захоплювати оригінальний вміст екрана, навіть коли увімкнено екранну завісу або вбудовану лупу NVDA.

Конфіденційні дані деяких сеансів входу захищено за допомогою Windows DPAPI. Інші збережені ключі API зберігаються у конфігурації NVDA у вигляді незашифрованого тексту. Враховуйте це перед створенням або поширенням переносної копії NVDA.
